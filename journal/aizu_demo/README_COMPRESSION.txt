BST-ID whole-scenario compression analysis

Place these files in:
  C:\work\bst-id\journal\aizu_demo\

Required input:
  utm_scenario.json
generated by the current operation-composition / 5-8-10 m/s scenario generator.

Run:
  cd C:\work\bst-id
  python journal\aizu_demo\analyze_compression.py

Outputs:
  journal\aizu_demo\compression_analysis\
    compression_report.md
    compression_summary.json
    compression_summary.csv
    axis_merge_summary.csv
    zoom_distribution.csv
    attribute_cardinality_distribution.csv
    flight_summary.csv
    fixed_interval_records.csv.gz
    normalized_xyht_records.csv.gz

The main fair baseline is:
  fixed z21/z21/H12 + exact dyadic T prefixes
versus:
  attribute-preserving normalized XYHT BST-ID prefixes

The analyzer also reports:
  - 1-second fixed-grid cell-time baseline
  - fixed-grid arbitrary exact intervals (strong practical baseline)
  - X/Y/H/T merge counts
  - X/Y anisotropic rectangular-prefix fraction
  - overlap attribute-cardinality distribution
  - 5/8/10 m/s per-flight context

Optional figures:
  python -m pip install matplotlib
  python journal\aizu_demo\make_compression_figures.py

The plotting script writes four PNGs under compression_analysis/.

To skip large full-record CSV.GZ dumps:
  python journal\aizu_demo\analyze_compression.py --no-record-dumps
